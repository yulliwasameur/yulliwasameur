### Yulliwas Ameur — Associate Professor in cybersecurity

Efrei Research Lab (Paris) · associate member of CEDRIC (Cnam) ·
[Website](https://yulliwasameur.github.io) · [ORCID](https://orcid.org/0000-0003-1435-2982)

*Enseignant-chercheur en cybersécurité. Mes travaux suivent trois axes : la sécurité des agents IA, le numérique pour le kabyle, et la cryptographie post-quantique et homomorphe.*

---

#### 🛡️ Axis 1 — Security of LLMs and AI agents

How to give an AI agent tools, memory and delegated authority without losing control of what it does.

| Repository | What it is |
|---|---|
| [masked-mandates](https://github.com/yulliwasameur/masked-mandates) | Unlinkable, attenuable and accountable delegation for LLM agents (BBS+, accumulators, Bulletproofs++), Rust prototype with a 96-attack suite |
| [linera](https://github.com/yulliwasameur/linera) | LinEra: lineage-complete, forward-secure cryptographic erasure for LLM-agent memory |
| [schemacaps-artifact](https://github.com/yulliwasameur/schemacaps-artifact) | SchemaCaps: when a compatible tool update silently widens an agent's authority (ICAART 2027) |
| [pi-loc](https://github.com/yulliwasameur/pi-loc) | Do prompt-injection detectors look at the injection? An explainability audit of agent guardrails |
| [GovSecLLMpp-SECAI2026](https://github.com/yulliwasameur/GovSecLLMpp-SECAI2026) | GovSecLLM++: compliance-aware security benchmark for LLM applications (SECAI 2026 artifact) |
| [securite-agents-ia-cours](https://github.com/yulliwasameur/securite-agents-ia-cours) | Open course in French on AI-agent security: 10 modules, 133 slides, CC BY 4.0 ([DOI](https://doi.org/10.5281/zenodo.23732189)) |
| [cyber-research-radar](https://github.com/yulliwasameur/cyber-research-radar) | World map of cybersecurity and cryptography conferences, CFP deadlines and journals, refreshed weekly |

#### ⵣ Axis 2 — Kabyle and low-resource languages

Open tools and datasets so that Kabyle (Taqbaylit) can be read, written and processed by machines.

| Repository | What it is |
|---|---|
| [kabocr](https://github.com/yulliwasameur/kabocr) | KabOCR: free OCR for Kabyle (Latin script). Runs in the browser ([try it](https://yulliwasameur.github.io/kabocr/)), CLI, open model and evaluation tool ([DOI](https://doi.org/10.5281/zenodo.24111659)) |
